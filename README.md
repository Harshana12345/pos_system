# POS System API

Express.js backend scaffold for the POS system.

## Project Structure

```text
src/
  app.js
  server.js
  config/
  controllers/
  database/
  middlewares/
  models/
  routes/
  services/
  utils/
  validators/
tests/
docs/
```

## Setup

```bash
npm install
npm run dev
```

The API defaults to `http://localhost:5000`.

## Health Checks

- `GET /health`
- `GET /api/v1/health`
